Exemplos em PHP para criação de cobranças Pix e validação de Webhooks Fan-Out

Para que seus projetos (Sua Loja, Seu Salão, FaceCraft) criem pagamentos através do CJC-Dev-Pays, basta enviar uma requisição HTTP simples com a chave da aplicação:

1. Criar Cobrança Pix em PHP (cURL ou SDK)

$response = file_get_contents('http://localhost:4020/api/v1/payments/pix', false, stream_context_create([
    'http' => [
        'method'  => 'POST',
        'header'  => "Content-Type: application/json\r\n" .
                     "X-Api-Key: SUA_CHAVE_CJC_LIVE\r\n",
        'content' => json_encode([
            'external_reference' => 'SUALOJA-PEDIDO-1002',
            'amount'             => 49.90,
            'description'        => 'Pedido #1002 - Lanche X-Burger',
            'payer'              => [
                'email'          => 'cliente@email.com',
                'first_name'     => 'Caua',
                'identification' => ['type' => 'CPF', 'number' => '12345678909']
            ]
        ])
    ]
]));

$data = json_decode($response, true);
$qrCodeBase64 = $data['payment']['qr_code_base64'];
$copiaCola    = $data['payment']['qr_code'];

2. Receber o Webhook Fan-Out no seu Script PHP (`webhook/cjc-pays.php`)

<?php
$payload = file_get_contents('php://input');
$signatureHeader = $_SERVER['HTTP_X_CJC_SIGNATURE'] ?? '';

// Extrai timestamp e hash
parse_str(str_replace(',', '&', $signatureHeader), $sigParts);
$timestamp = $sigParts['t'] ?? '';
$receivedHash = $sigParts['v1'] ?? '';

// Valida assinatura HMAC
$secret = 'SEU_WEBHOOK_SECRET_AQUI';
$expectedHash = hash_hmac('sha256', "t={$timestamp}&body={$payload}", $secret);

if (!hash_equals($expectedHash, $receivedHash)) {
    http_response_code(401);
    die('Assinatura inválida');
}

$event = json_decode($payload, true);
if ($event['status'] === 'approved') {
    $ref = $event['external_reference'];
    // Atualiza status do pedido no seu banco MySQL para PAGO!
}

http_response_code(200);
echo json_encode(['status' => 'received']);
